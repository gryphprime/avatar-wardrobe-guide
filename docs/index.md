# Avatar Wardrobe and Avatar Outfit Toggles

## Use the tools to manage avatar outfits

Use Avatar Wardrobe to find and add compatible outfits. Use Avatar Outfit Toggles to create VRChat menu controls for clothing and accessories.

This guide is for people who are new to Unity as well as people who have used Unity before. You do not need to write animations or edit scripts to follow these instructions.

## Choose a task

### Add an outfit

Use Avatar Wardrobe to browse the outfit assets in your Unity project, check compatibility, review details, and add an outfit to the avatar you are editing.

[Add an outfit](add-an-outfit.md)

### Create menu controls for an outfit

Use Avatar Outfit Toggles when an outfit is already in your scene or when you want to update its controls. The tool creates a submenu and controls for the outfit.

[Create outfit toggles](outfit-toggles.md)

## How the tools work together

1. Find an outfit and check whether it matches your avatar.
2. Install the outfit on the avatar instance in your scene.
3. Create controls that turn the outfit or its parts on and off in VRChat.

You can use either tool on its own. Avatar Wardrobe can also create controls when you add an outfit.

## Work with the avatar instance

Work with the avatar instance in Unity's **Hierarchy**. The avatar instance is the copy of the avatar placed in your current scene. It is the version that you edit.

!!! tip "Undo changes when needed"
    Save the project before you make a major change. To undo a change, select **Edit**, then **Undo**.
